# Carta

Repositório com projetos pequenos para uso em mesa de RPG.

## Arquivo Oculto — fichas de RPG

Uma ficha digital e responsiva inspirada na organização das fichas de **Ordem Paranormal RPG**, publicada na pasta `fichas/`.

- [Abrir o aplicativo (código HTML)](fichas/index.html)
- [Ver os arquivos do aplicativo](fichas/)

### Como usar

1. Abra `fichas/index.html` no navegador. O arquivo HTML funciona localmente, sem conexão com a internet.
2. Os personagens são salvos automaticamente no armazenamento local do navegador.
3. Use **Exportar** para criar um backup JSON e **Importar** para recuperar fichas.
4. Use **Imprimir** para gerar uma versão em papel ou PDF.

Para disponibilizar a versão instalável pelo navegador, publique o repositório com GitHub Pages e abra a pasta `/fichas/` pelo endereço HTTPS. Após a primeira visita online, o service worker armazena os arquivos necessários para abrir o app offline.

O projeto é independente e não oficial, sem vínculo com Jambô Editora ou os criadores de Ordem Paranormal. Consulte as regras da sua mesa para confirmar cálculos e valores.
